# RR jump to chapter content

When loading a chapter, automatically scroll to the beginning of content, skipping the ad and the shoutout (basically a second ad). 

I slapped this together because the paracontent was several screenlengths long on my boox palma, and the graphics would cause ghosting on the eink display. I personally use this in firefox for android with violentmonkey. 

## Install

1. Install a userscript manager:
   - [Violentmonkey](https://violentmonkey.github.io/)
2. Open [`royalroad-jump-to-content.user.js`](royalroad-jump-to-content.user.js) and click **Raw**, or copy the file's contents into a new script in your userscript manager.
3. The script runs automatically on chapter pages:
   - `https://www.royalroad.com/fiction/*/*/chapter/*`
   - `https://royalroad.com/fiction/*/*/chapter/*`
